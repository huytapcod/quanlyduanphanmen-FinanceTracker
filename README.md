# 📊 Finance Tracker - MERN App

Ứng dụng quản lý tài chính cá nhân (Thu nhập / Chi tiêu) được xây dựng với **MERN Stack** (MongoDB, Express, React, Node.js).

## 🚀 Tính năng

- Thêm / sửa / xóa giao dịch (thu nhập hoặc chi tiêu).
- Lọc giao dịch theo ngày, trạng thái.
- Phân trang danh sách giao dịch.
- Biểu đồ thống kê:
  - So sánh **Tổng Thu nhập vs Tổng Chi tiêu**.
  - Phân tích giao dịch theo **Category**.
  - Biểu đồ đường theo thời gian.
- Giao diện responsive, dễ sử dụng.

## 🛠️ Công nghệ sử dụng

- **Frontend**: React, Vite, TailwindCSS, Recharts, MUI
- **Backend**: Node.js, Express.js, MongoDB, Mongoose
- **API giao tiếp**: Axios

## ⚙️ Cài đặt & chạy dự án

### 1. Clone repo
```bash
git clone https://github.com/<your-username>/quanlyduanphanmen-FinanceTracker.git
cd quanlyduanphanmen-FinanceTracker
2. Backend (server)
cd server
npm install
npm run dev
3. Frontend (client)
cd client
npm install
npm run dev
Mặc định chạy ở: http://localhost:5173
